# 关于 & 隐私政策

最后更新日期：2026年9月

## 概述

本网站是一个静态博客，基于 [Fuwari](https://github.com/saicaca/fuwari) 构建，我们非常重视您的隐私。本隐私政策说明了当您访问本站时，可能被收集、使用和披露的信息。

## 网站性质

本站是一个静态网站，这意味着：

- 我们不会在服务器端存储您的个人信息
- 网站内容是预先生成的，不会动态处理用户数据
- 我们不会主动收集或存储您的个人信息

## 服务器与托管

本站部署在自建的香港服务器上，不经过第三方 CDN 平台。服务器的访问日志（IP 地址、访问时间、请求路径、浏览器信息）由服务器软件自动生成，仅用于故障排查与安全防护，不会用于其他用途。

## 第三方服务

本站本身不接入任何第三方统计或广告服务。可能涉及的第三方服务如下：

### 评论服务

**Giscus**

- 基于 GitHub Discussions 的评论系统
- 可能收集的信息：GitHub 账户信息（仅在您主动登录评论时）
- 特点：不使用 Cookie，不追踪用户
- 隐私政策：[GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

### 其他外部资源

页面可能引用部分公共资源（如字体、图标），这些请求会由对应的服务方接收，具体请参考各服务方的隐私政策。

## Cookie 和本地存储

本站**不使用第三方 Cookie**，也不使用任何统计或广告 Cookie。

我们仅使用浏览器本地存储（localStorage）保存您的前端偏好设置，例如：

| 用途 | 存储类型 | 是否需要同意 |
|------|----------|-------------|
| 主题 / 显示偏好 | 本地存储 | ❌ 否（功能必需） |
| 页面状态（如滚动位置） | 会话存储 | ❌ 否（功能必需） |

### 如何清理浏览器数据

如果您希望清除本站保存在本地的设置，可按以下步骤操作：

**Chrome / Edge**：设置 → 隐私和安全 → 清除浏览数据 → 勾选"Cookie 和其他网站数据" → 清除数据

**Firefox**：设置 → 隐私与安全 → Cookie 和网站数据 → 清除数据

**Safari**：偏好设置 → 隐私 → 管理网站数据 → 搜索本站域名 → 移除

> 💡 提示：清除后，您的主题偏好等本地设置也会被重置。

## 您的权利

您有权：

- 了解我们收集的信息类型
- 要求删除您的个人信息（如适用）
- 选择退出某些数据收集
- 禁用 Cookie 和 JavaScript（可能影响网站功能）

## 如何保护您的隐私

您可以通过以下方式保护您的隐私：

- 使用隐私浏览模式
- 禁用第三方 Cookie
- 使用广告拦截器
- 使用 VPN 服务
- 定期清理浏览器数据

## 数据安全

虽然我们不直接收集您的个人信息，但我们：

- 使用 HTTPS 加密传输
- 定期更新服务端软件与依赖
- 最小化第三方服务的接入
