# 隐私政策

最后更新日期：2026年9月20日

## 概述

本网站是一个静态博客，基于 [Fuwari](https://github.com/saicaca/fuwari) 构建，我们非常重视您的隐私。本隐私政策说明了当您访问本站时，可能被收集、使用和披露的信息。

## 网站性质

本站是一个静态网站，这意味着：

- 我们不会在服务器端存储您的个人信息
- 网站内容是预先生成的，不会动态处理用户数据
- 我们不会主动收集或存储您的个人信息

## 服务器与托管

本站部署在自建的香港服务器上，并通过 **Cloudflare CDN** 提供全球加速与安全防护：

- 所有访问请求会先经过 Cloudflare 的全球边缘节点，再回源到源站服务器
- 作为 CDN 服务商，Cloudflare 会处理请求的网络元数据（如 IP 地址、User-Agent、请求路径等），用于内容分发、安全防护（Web 应用防火墙、DDoS 缓解）与网络优化，详见 [Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)
- 源站服务器的访问日志（IP 地址、访问时间、请求路径、浏览器信息）由服务器软件自动生成，仅用于故障排查与安全防护，不会用于其他用途

## 第三方服务

本站本身不接入任何第三方统计或广告服务。可能涉及的第三方服务如下：

### CDN 服务

**Cloudflare**

- 为本站提供 CDN 加速、DDoS 防护与 Web 应用防火墙
- 可能处理的信息：IP 地址、请求头、访问日志等网络元数据
- 隐私政策：[Cloudflare 隐私政策](https://www.cloudflare.com/privacypolicy/)

### 评论服务

**Giscus**

- 基于 GitHub Discussions 的评论系统
- 可能收集的信息：GitHub 账户信息（仅在您主动登录评论时）
- 特点：不使用 Cookie，不追踪用户
- 隐私政策：[GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)

### 统计服务

**Umami**（自建）

- 本站使用自行部署的 [Umami](https://umami.is/)（umami.bihrys.com）统计访问情况，不接入任何第三方统计平台
- 特点：不使用 Cookie、不采集个人身份信息，仅记录匿名化的页面浏览量、访客数、访问来源、设备类型等聚合数据
- 统计数据由本站自行托管，不会提供给第三方

### 其他外部资源

页面可能引用部分公共资源（如字体、图标），这些请求会由对应的服务方接收，具体请参考各服务方的隐私政策。

## Cookie 和本地存储

本站**不使用任何统计或广告 Cookie**。经 Cloudflare CDN 处理的请求，可能因安全防护需要（如 Bot 管理、人机验证）由 Cloudflare 设置必要的安全 Cookie（例如 `__cf_bm`），此类 Cookie 仅用于安全目的，不用于追踪或广告。

我们仅使用浏览器本地存储（localStorage）保存您的前端偏好设置，例如：

| 用途 | 存储类型 | 是否需要同意 |
|------|----------|-------------|
| 主题 / 显示偏好 | 本地存储 | ❌ 否（功能必需） |
| 页面状态（如滚动位置） | 会话存储 | ❌ 否（功能必需） |

### 如何清理浏览器数据

如果您希望清除本站保存在本地的设置，可按以下步骤操作：

**Chrome / Edge**：设置 → 隐私和安全 → 清除浏览数据 → 勾选"Cookie 和其他网站数据" → 清除数据

**Firefox**：设置 → 隐私与安全 → Cookie 和网站数据 → 清除数据

**Safari**：偏好设置 → 隐私 → 管理网站数据 → 搜索本站域名 → 移除

> 💡 提示：清除后，您的主题偏好等本地设置也会被重置。
